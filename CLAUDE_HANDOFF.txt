## 1. Product Mission & Scope

**Nyaya AI** (from Sanskrit *NyÄya* meaning "justice", "logic", and "due process") is an AI-powered civic legal assistance platform engineered for ordinary Indian citizens navigating consumer disputes.

In India, ordinary consumers frequently face defective goods, e-commerce refund refusals, delivery failures, and service deficiencies from merchants, airlines, telecommunications providers, and developers. While the **Consumer Protection Act, 2019** provides strong statutory remedies, average citizens lack the legal fluency to structure their claims, identify missing evidence, cite applicable legal sections, or draft formal legal notices.

Nyaya AI bridges this gap as an **informational legal assistant** combining:
- **Kuku FM-inspired warm, approachable visual identity**: welcoming, non-intimidating citizen experience.
- **Stripe-inspired premium visual quality**: rigorous micro-interactions, responsive grid layout, and accessible visual hierarchy.
- **Notion-inspired document drafting**: live editable clauses with inline statutory grounding tags.
- **Distinctive original Nyaya AI identity**: grounded strictly in authentic Indian statutory acts without hallucination.

> **Statutory Disclaimer**: Nyaya AI provides informational legal assistance and research automation based on public Indian statutes. It does not constitute formal legal counsel or create an advocate-client relationship under the Advocates Act, 1961.

### 2. Backend Setup & Run

The backend is built with FastAPI and runs on port `8000`.

```bash
# Navigate to backend directory
cd backend

# Create a Python virtual environment (if not already created)
python -m venv venv

# Activate virtual environment
# Windows PowerShell:
.\venv\Scripts\Activate.ps1
# macOS/Linux:
# source venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Start FastAPI development server with auto-reload
uvicorn app.main:app --reload --port 8000
```

Once started:
- **API Root**: [http://localhost:8000/](http://localhost:8000/)
- **Health Check**: [http://localhost:8000/api/health](http://localhost:8000/api/health)

# Nyaya AI Architecture Specification

## 1. System Overview

**Nyaya AI** (à¤¨à¥à¤¯à¤¾à¤¯ AI) is an AI-powered legal assistance platform engineered specifically for ordinary Indian citizens facing consumer disputes under the **Consumer Protection Act, 2019**, **Consumer Protection (E-Commerce) Rules, 2020**, and related statutory frameworks.

The architectural foundation guarantees **grounded legal precision and zero hallucination**:
- Every statutory section cited must originate from an indexed, verified legal database.
- Every complaint draft produced must follow established Indian consumer forum jurisdictions (District Commission, State Commission, NCDRC).
- The AI architecture cleanly separates probabilistic conversational intake from deterministic statutory verification.

## 4. Replaceable Provider Abstraction

Nyaya AI decouples all generative AI and embedding logic from third-party vendor SDKs via abstract base classes:

### LLM Interface (`backend/app/ai/llm/base.py`)
```python
class BaseLLMProvider(ABC):
    @abstractmethod
    async def generate(self, prompt: str, system_prompt: Optional[str] = None, temperature: float = 0.0, max_tokens: int = 1024, **kwargs: Any) -> str:
        """Generate complete text response."""
        pass

    @abstractmethod
    async def stream(self, prompt: str, system_prompt: Optional[str] = None, temperature: float = 0.0, max_tokens: int = 1024, **kwargs: Any) -> AsyncIterator[str]:
        """Stream response tokens asynchronously."""
        pass
```

- **`MockLLMProvider`**: Used for unit tests, offline development, and CI environments without network latency or API costs.
- **`GeminiLLMProvider`**: Primary provider interface for Google Gemini API models (`gemini-1.5-pro`).
- **`get_llm_provider(settings)`**: Factory that instantiates the active provider based on the `LLM_PROVIDER` environment variable.

from app.core.config import Settings
from app.ai.llm.base import BaseLLMProvider
from app.ai.llm.mock_provider import MockLLMProvider
from app.ai.llm.gemini_provider import GeminiLLMProvider


def get_llm_provider(settings: Settings) -> BaseLLMProvider:
    """
    Factory function to instantiate the configured LLM provider.
    Allows seamless switching between mock and Gemini providers without altering business logic.
    """
    provider_name = settings.LLM_PROVIDER.lower().strip()

    if provider_name == "mock":
        return MockLLMProvider()
    elif provider_name == "gemini":
        return GeminiLLMProvider(
            api_key=settings.GEMINI_API_KEY,
            model=settings.GEMINI_MODEL
        )
    else:
        raise ValueError(
            f"Unsupported LLM_PROVIDER: '{settings.LLM_PROVIDER}'. Supported options: 'mock', 'gemini'."
        )
